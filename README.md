# dsal3389.xyz

Personal portfolio and Markdown-first blog built with Astro.

## Commands

```sh
npm install
npm run dev
npm run build
```

## Content

- Site identity and navigation live in `src/site.config.ts`.
- Blog posts live in `src/content/blog` as `.md` or `.mdx`.
- Project case studies live in `src/content/projects` as `.md` or `.mdx`.
- Use normal Markdown image syntax, for example `![Alt text](/images/blog-workspace.svg)`.
- Use MDX imports when a post needs custom components from `src/components/content`.
