Astro is a good fit for a portfolio because most pages are content, not application state. The default path should be static HTML with selective interactivity.

<Callout title="Rule of thumb">
If a page can be rendered at build time, render it at build time. Add client JavaScript only for controls that genuinely need it.
</Callout>

## Practical checklist

- Keep project and post data in content collections.
- Use MDX for posts that need components.
- Keep images local and give them useful alt text.
- Avoid shipping a large UI runtime for static sections.
- Run `npm run build` before deployment.
